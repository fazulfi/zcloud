## External dependencies (founder action)

### Google OAuth console (M1.12B)

Create an OAuth 2.0 Client ID (Web application) in Google Cloud Console:

| Field | Value |
|-------|-------|
| Authorized redirect URI | `https://api.zrouter.dev/api/v1/auth/oauth/google/callback` |
| Authorized JavaScript origins | `https://app.zrouter.dev` |
| Frontend post-login route | `https://app.zrouter.dev/auth/oauth/callback` |

After creation, store in admin settings (DB settings table): `google_oauth_enabled=true`,
`google_oauth_client_id`, `google_oauth_client_secret`, `google_oauth_redirect_url`
(backend callback absolute), `google_oauth_frontend_redirect_url`.
